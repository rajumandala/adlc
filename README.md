# AI in the SDLC

Security notes on using AI to build software: AI coding assistants, coding agents with repository access, and AI-written tests and evals.

These notes continue the [main course on AI application security](https://github.com/rajumandala/aisec-notes), which builds an AI order assistant inside a broker's trading app. Here, the same assistant is built by a team that uses AI to write, review and test its code.

Start with [S0. AI in the SDLC](notes/S0.%20AI%20in%20the%20SDLC.md). Notes are in progress.
